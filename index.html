About

What is a Metronome?

A metronome produces a steady beat to help musicians maintain a consistent tempo during practice. It is an essential tool for players of any instrument — piano, guitar, violin, drums and more — for building reliable rhythmic accuracy.

Features

  • BPM range 20 – 240, covering everything from the slowest to the fastest pieces
  • Time signatures: 1/4, 2/4, 3/4, 4/4, 3/8, 6/8, 9/8, 12/8
  • Subdivisions: quarter note, eighth note, triplet, and sixteenth note
  • Pendulum animation for visual beat tracking
  • Precise click sound via the Web Audio API
  • Dark / Light theme with preference saved locally
  • Runs in the browser with no installation required (PWA-ready)

How to Use

Click the BPM number to type a value directly. You can also adjust the tempo with the +/− buttons, the slider, the mouse wheel, or by swiping up and down on the BPM display. Select a time signature and subdivision, then press the play button to start. The spacebar works as a play/stop shortcut.

Practice Tips

Start at 60–70% of your target tempo and build clean technique before increasing speed. A good rule: if you can play something correctly five times in a row, raise the BPM by 5. Use triplet or sixteenth-note subdivision to sharpen rhythmic precision within each beat.
